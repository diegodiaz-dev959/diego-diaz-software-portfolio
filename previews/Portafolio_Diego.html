Seguimiento comercial con reglas que protegen el pipeline.

TypeScript · Node.js · SQLite

Funciones implementadas

  • Pipeline de cinco etapas y captura de oportunidades.
  • Revisiones para detectar cambios simultáneos.

PROYECTO 05 / EVENTOS E INCIDENTES

SignalOps

Procesar señales repetidas o antiguas sin generar ruido operativo.

TypeScript · HMAC-SHA256 · SQLite

Funciones implementadas

  • Apertura tras tres fallos y recuperación tras dos señales OK.
  • Reconocimiento y auditoría de incidentes.
  • Firma de eventos, ventana temporal y deduplicación.

Decisión que puedes explicar

Eventos repetidos no alteran contadores; firmas vencidas o manipuladas se rechazan.

Prueba las demos en tu PC

  1. Instala Node.js 24 y Python 3.10 o posterior.
  2. Descomprime el ZIP y abre la carpeta Portafolio_Diego.
  3. En Windows, abre iniciar.bat. En terminal, ejecuta el comando de abajo.
  4. Visita http://localhost:8080 y entra con demo / Demo-2026!
node server.ts

El ZIP incluye los cinco README, las pruebas, el código de las demos y las descripciones para el CV.

Proyectos de portafolio con datos de muestra. No representan empleos ni resultados de clientes. La revisión visual en navegador no pudo completarse en el entorno de creación; las 44 pruebas comprobadas son de dominio, API y motores Python.
